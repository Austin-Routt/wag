  becomes bad_outweighs(A,G): that A has bad consequences that outweigh
  the goal G. A plain side effect is argued as negative consequences, a
  rebuttal at the argument's conclusion; the claim that it outweighs G is
  the exception, answered by an argument that names the side effect and
  the comparison (below). 22.4/CQ7 and 22.1/CQ5 target it, and so will
  the game's CQ:side_effect (step C5) (Readings, 2).
- **D030.** The necessary-condition scheme separates the goal's

**Readings.** Each follows from a decision's text and its reasons; none
departs from one.
1. **One formula for one conflicting goal.** D004 reuses practical_reasoning2's
  predicate "to keep one formula for one idea", scoped to the agent and the
  goal. A scoped predicate in one scheme and an unscoped one in the other
  would be two formulas, so both become incompatible_goal(P,G); the
  condition schemes' conflicting goal takes the same formula, not the
  library's conflicting_goals(P,A). incompatible_goal/1 is left as an
  orphan template.
2. **The side effect that outweighs is D055's bad_outweighs(A,G).** D070
  renames the exception "for a side effect claimed to outweigh the reasons
  for the action". The reason for the action is its goal G (in
  practical_reasoning1, a goal that promotes V), and a side effect is a
  bad consequence of A; D055 already formalizes the claim that A's bad
  consequences outweigh G, as positive_consequences' exception. By D004's
  reason it is the same formula: a practical argument and a consequence
  argument for the same A and G then share the exception, as they should,
  since one comparison defeats both; with a second predicate, a weighing
  answered at one would leave the other standing. The book's 22.4/CQ7
  already asks only about consequences that outweigh G. It follows that
  D075's "side effect that outweighs" is C003's bad_outweighs_good, so
  that C003's pair (D064, planned for the consequences proposal) comes in
  here. D075's first answer schemes are then three: C003's pair, of which
  bad_outweighs_good is also the side effect that outweighs, and
  better_means. S1 leaves the exception: a side effect is a consequence of doing
  A in the game's one deliberation context. side_effects/2 is left as an
  orphan template.
3. **D030's repair, and its twin.** D030 names 22.2 and adopts the
  separation "as the schemes library has it, so that no variable is left
  unbound"; the convergence review recommended the library's repair as the
  starting point, without its conclusion should_do(P,X), which would
  pre-empt D063. The repair here is the library's record, with D004's
  conflicting goal and D063's conclusion; it states the agent in each
  premise, so that the first-person templates ("I have selected ...") no
  longer sit beside a third-person P, and gives the set of means its own
  variable S. 22.3, the sufficient-condition schema, has the same unbound
  variables and the same possibility assumption, so it takes the same
  repair; its alternatives premise was the necessary-condition one ("at
  least one ... is necessary"), where the book's S2 says that each one is
  sufficient, and becomes alternative_action_sufficient(P,S,A). Templates
  for the scoped predicates, goal_of_agent/2 among them, are in our own
  words (the library's repeat the book's premises). alternative_means is 3-ary here and 2-ary in
  two_person_practical until C4 brings that scheme to its library form
  (alternative_means(A,X,Y)); the CHANGELOG lists such pairs.
4. **Positive binding (D063, D075 refined).** An answer to an exception
  must not pass because nobody showed it is about another agent. The
  consequence answers bind the action A, whose identity names its agent
  ("governments putting a tax on meat", as the gold's bindings do), through
  their own premise brings_about(A,H). better_means binds the agent P
  through goal_of_agent(P,G), the answered argument's own goal premise,
  and states that P can do A2. Neither exception names the agent, so the
  engine cannot refuse an answer whose P is another agent; the game does,
  with the CQ answer contract (stage 2, items C5 and F): an answer whose
  goal premise is not the answered argument's, or whose agent is not the
  game's deliberating agent (named in its profile), is refused, with a
  test of each.
5. **Premise order.** goal_of_agent(P,G) comes first, where the book
  prints the goal premise. Nothing reads premises by position (the gold
  compares them as sets).
